# プロジェクト概要(提出用の下書き)

## 名前
リンちゃん ― わすれても、だいじょうぶ

## ひとことで
認知症の家族と、まわりの家族の「伝わらない」を両方向から減らす、iPad に置いておく黒い犬の「リンちゃん」。

## 解決したいこと
作者の家族の困りごとから生まれました。もの忘れが増えた本人と家族の間では、毎日こんなことが起きています。

- 物の置き場所や使い方が分からなくなり、同じことを何度も聞く。家族は疲れてしまう
- 「あれ」「あの」が増え、言いたい物が言葉にならない。ジェスチャーでも伝わらない
- 家族の言葉が本人に届かず、何度も言い直す。言い方がきつくなってしまう

## リンちゃんがすること
- **聞けば、写真で答える**:「眼鏡どこ?」に、家族が登録した内容だけを根拠に答え、部屋の写真に赤い丸で置き場所を見せる。何度聞かれても同じ調子で。分からないことは推測せず「お母さんに聞いてみましょうね」
- **「あれ」を写真で伝える**:会話と時間帯から候補を推測し、写真2〜3枚で「これですか?」。外れたら「物・人・場所」の大きなボタン
- **家族の言葉を伝える**:「これ食べなさい、体にいいから」を「これ、体にいいですから、ひとくち食べませんか」と、意味を変えずにやわらかく言い直す
- **聞き返しに合わせて言い直す**:1回目は短く、2回目は一言と大きな文字で、3回目は「大丈夫ですよ」とやさしく終える
- **家族の関わりを増やす**:家族の声の伝言(字幕つき・返事を残す)、デイサービスの帰宅後の声かけ、思い出の話題、家族への報告(本人の話と確かめられた事実を分けて書く)、言葉の辞書の候補

## Claude の使い方
- **会話(Haiku)**:返事の速さを優先。訂正しない・推測しない・診断しない・記憶を試さない、をプロンプトで徹底。テレビの音への返事も、呼び出しを増やさずプロンプトの中で判定
- **「あれ」の推測・家族の言葉の言い直し(Haiku + Structured Outputs)**:登録にある名前だけを返させ、画面の写真とつなぐ
- **言葉の辞書の候補・家族への報告(Sonnet + Structured Outputs、サーバー側フォールバック)**:記録の読み解き
- **返事の質のテスト**:試用で見つかった場面も含む21の場面で、方針を守れているかを自動で確かめる(`npm run eval`)
- **開発**:Claude Code と一緒に、計画 → 作る → 試用 → 直す、を5日間で回した。試用ノートは Claude が直接読み、次の修正の計画に使った

## 試用から学んだこと
家族と実際に試用し、記録と付き添いの家族のメモをもとに直しました(README の「試用から学んで直したこと」)。たとえば、本人が画面の文字を読み上げてしまうことが分かり、画面から指示の文字をなくしました。「何の番組でしたか」のような記憶を試す質問が本人を困らせることも分かり、問いかけ方を変えました。

## プライバシーと安全
- 家族の情報(写真・呼び名・会話の記録・声)は **iPad の中だけ** に保存。サーバーは Claude への中継だけで何も保存しない。写真は Claude に送らない
- 医療の判断や診断はしない。家族の代わりではなく、家族の関わりを増やす道具
- 公開リポジトリには架空のサンプルとイラストだけ
