# デモ動画の台本(3分・下書き)

審査基準(インパクト 30% / デモ 25% / Claude の活用 25% / 深さと実行 20%)に合わせて、「困りごと → 実際に伝わる場面 → 家族の側 → 設計」の順に見せる。

## 撮影のきまり

- 本人は**声と手元だけ**。顔は映さない(家族の許可済みの範囲)
- 画面に映る呼び名・写真・伝言は、公開してよいものだけにする。迷うものは `samples/` の架空データで撮り直す
- 施設名・お店の名前・住所が映らないようにする
- iPad は Safari で開く(ホーム画面のアイコンからは開かない)。画面収録はマイクなしで行い、音声は別に録る

## 構成

| 時間 | 場面 | 画面 | ナレーション(案) |
|---|---|---|---|
| 0:00–0:20 | 困りごと | 家族の会話の再現、または文字だけ | 「何度も聞き返す。『あれ』が何か分からない。言いたいことが伝わらないのは、本人も家族もつらい」 |
| 0:20–0:30 | リンちゃんの紹介 | 置きっぱなしの話す画面(日付と時刻、リンちゃん、マイクのボタン) | 「家族が写真と短い説明を登録しておけば、本人は話しかけるだけ」 |
| 0:30–0:55 | 聞いて、写真で答える | 「眼鏡どこ?」→ 呼び名で呼びかけてから答え、**部屋の写真に赤い丸** →(押さずに)「え?」→ 短い言い直し | 「何度聞かれても同じ調子で。置き場所は写真で。返事も、押さずにそのまま聞き取る」 |
| 0:55–1:30 | **「あれ」を写真で伝える(見せ場)** | 「ほら、あれ、歯にはさまったのを取る…」→ 楊枝の写真「これですか?」→ タップ → 答える。外れたときの3ボタンも短く | 「言葉が出なくても、写真なら選べる。会話と時間帯から Claude が候補を絞る」 |
| 1:30–1:55 | **ご家族が伝える** | 祖父が「これ食べなさい、体にいいから」→「これ、体にいいですから、ひとくち食べませんか」と大きな文字 → 本人が答える | 「家族の言葉も、意味は変えずにやわらかく。何度も言うつらさを、リンちゃんが引き受ける」 |
| 1:55–2:10 | 家族の伝言 | 伝言を押す → 字幕つきで家族の声 → 本人が返事 →「伝えておきますね」 | 「家族の声で、字幕つきで。返事は家族に届く」 |
| 2:10–2:30 | 試用から学んだこと | README の「試用から学んで直したこと」の表、試用ノート | 「実際に試して、画面の文字を読み上げてしまうこと、記憶を試す質問が負担になることが分かった。記録をもとに直した」 |
| 2:30–2:50 | 家族の側と設計 | 家族の登録(部屋の写真で置き場所)→ 報告と言葉の辞書の候補 → プライバシーの図 | 「家族の情報は iPad の中だけ。会話は Haiku で速く、記録の読み解きは Sonnet。診断はしない」 |
| 2:50–3:00 | 締め | リンちゃん | 「わすれても、だいじょうぶ」 |

## 再現モード(`/replay`)で撮る

本人の顔や本物の呼び名を映さずに撮るための、架空の台本の再生ページ。台本は `samples/replay.json`。

- Mac のブラウザで `/replay` を開き、QuickTime などで画面と音を収録する。場面ごとに再生できる
- 再生中は右下に「再現」と出る。本物の場面だと誤解されないよう、消さない。動画でも「再現」と分かるように言う
- 「試用の記録から作る」で、試用の流れを台本にできる。話の中に本物の名前や場所が残ることがあるので、全部読んで直してから撮る
- 再現モードは Claude を呼ばない。「実際に動いている」場面は、本物の画面でも撮って入れる

## 撮る前の準備

1. 家族の登録画面で、映してよい物・人・場所を写真つきで登録する(楊枝、眼鏡、給湯器など)。物は「どこにありますか?」で部屋の写真に置き場所を付けておく
2. 思い出の話題を1つ、デイサービスの日を当日にして帰宅時間を過ぎた時刻にしておく(「おかえりなさい」を出すため)
3. 伝言を1つ、字幕つきで録音しておく
4. 試用の記録(`/log`)に、言葉の辞書の候補が出るくらいの記録を作っておく(「あれ」→ 写真で選ぶ、を何回か)
5. 撮影前に `/log` の「記録を消す」で、余計な記録を消しておく(辞書の候補を撮ったあとに)

## 試用で撮れたら差し替えたい場面

- 本人が実際に写真を選んで「そう、これ」と言う場面(声と手元)
- 聞き返しの2回目で伝わった場面
- 家族が「伝わった」の集計を見る場面
