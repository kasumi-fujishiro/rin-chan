# デモ動画の台本(3分・下書き)

審査基準(インパクト 30% / デモ 25% / Claude の活用 25% / 深さと実行 20%)に合わせて、「困りごと → 実際に伝わる場面 → 家族の側 → 設計」の順に見せる。

## 撮影のきまり

- 本人は**声と手元だけ**。顔は映さない(家族の許可済みの範囲)
- 画面に映る呼び名・写真・伝言は、公開してよいものだけにする。迷うものは `samples/` の架空データで撮り直す
- 施設名・お店の名前・住所が映らないようにする
- iPad は Safari で開く(ホーム画面のアイコンからは開かない)。画面収録はマイクなしで行い、音声は別に録る

## 構成

| 時間 | 場面 | 画面 | ナレーション(案) |
|---|---|---|---|
| 0:00–0:20 | 困りごと | 家族の会話の再現、または文字だけ | 「何度も聞き返す。『あれ』が何か分からない。言いたいことが伝わらないのは、本人も家族もつらい」 |
| 0:20–0:35 | リンちゃんの紹介 | 話す画面、リンちゃんの表情が切り替わる | 「家族が写真と短い説明を登録しておけば、本人は話しかけるだけ」 |
| 0:35–1:05 | 聞いて、写真で答える+聞き返し | 「眼鏡はどこ?」→ 写真つきの返事 →「え?」→ 短い言い直し →「なに?」→ 大きな文字 | 「同じことを何度聞かれても、同じ調子で。聞き返されるたびに、短く、やさしい言葉に」 |
| 1:05–1:45 | **「あれ」を写真で伝える(見せ場)** | 「ほら、あれ、歯にはさまったのを取る…」→ 楊枝の写真「これですか?」→ タップ → 答える。外れたときの3ボタンも短く | 「言葉が出なくても、写真なら選べる。会話と時間帯から Claude が候補を絞る」 |
| 1:45–2:05 | リンちゃんから話しかける・家族の伝言 | 「おかえりなさい」のカード → 反応。お母さんからの伝言を押す | 「デイサービスの帰りや、好きな思い出の話題で、リンちゃんから声をかける。家族の声の伝言も」 |
| 2:05–2:35 | 家族の側 | 家族の登録画面 → 言葉の辞書の候補(「ズック=運動靴」「熱い↔冷たい」)→ 試用の記録の「伝わった」の集計 | 「『あれ』で選んだ記録から、本人の言葉の辞書が育つ。どの言い直しで伝わったかも残る」 |
| 2:35–2:55 | 設計 | README のプライバシーの図、Claude の使い方の表 | 「家族の情報は iPad の中だけ。会話は Haiku で速く、記録の読み解きは Sonnet。診断はしない」 |
| 2:55–3:00 | 締め | リンちゃん | 「わすれても、だいじょうぶ」 |

## 撮る前の準備

1. 家族の登録画面で、映してよい物・人・場所を写真つきで登録する(楊枝、眼鏡、給湯器など)
2. 思い出の話題を1つ、デイサービスの日を当日にして帰宅時間を過ぎた時刻にしておく(「おかえりなさい」を出すため)
3. 伝言を1つ録音しておく
4. 試用の記録(`/log`)に、言葉の辞書の候補が出るくらいの記録を作っておく(「あれ」→ 写真で選ぶ、を何回か)
5. 撮影前に `/log` の「記録を消す」で、余計な記録を消しておく(辞書の候補を撮ったあとに)

## 試用で撮れたら差し替えたい場面

- 本人が実際に写真を選んで「そう、これ」と言う場面(声と手元)
- 聞き返しの2回目で伝わった場面
- 家族が「伝わった」の集計を見る場面
